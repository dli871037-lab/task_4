# Расчет температурного поля двухслойной стенки

> **Автор:** Ли Даниил  
> **Задание:** Циклы с ветвлениями  
> **Вариант:** 13  

### Описание задачи
Программа рассчитывает стационарное распределение температуры в плоской двухслойной стенке и решает обратную задачу теплопроводности — находит координату `x`, в которой достигается заданная температура.

Программа демонстрирует использование цикла `for` с вложенным ветвлением `if-else`.

---

### 1. Физическая постановка

Дана двухслойная стена:
* Слой 1 (внутренний): толщина `d1` [см], теплопроводность `λ1` [Вт/(м·К)]
* Слой 2 (наружный): толщина `d2` [см], теплопроводность `λ2` [Вт/(м·К)]

На внутренней поверхности поддерживается температура `t1`, на наружной — `t2`. Тепловой поток стационарный, одномерный.

Требуется:
1. Найти температуру на границе слоев `tc`
2. Для `N` заданных значений температуры `T` найти координату, где эта температура достигается.

### 2. Математическая модель

Термическое сопротивление слоя: `R = d / λ`

Теплопроводность (величина, обратная сопротивлению, в коде `thermalConductance`):

```
g1 = λ1 / d1
g2 = λ2 / d2
```

Температура на стыке из условия равенства тепловых потоков:

```
tc = (g1 * t1 + g2 * t2) / (g1 + g2)
```

Распределение температуры внутри каждого слоя — линейное. Обратная интерполяция для поиска координаты `x(T)`:

Если искомая температура ближе к внутренней стенке (`T` находится в 1-м слое):

```
x = (T - t1) / (tc - t1) * d1
```

Если во 2-м слое:

```
x = (T - tc) / (t2 - tc) * d2 + d1
```

В программе `x` выводится в метрах (`/ 100.0`), хотя вводится в сантиметрах.

### 3. Алгоритм

1. Ввод исходных данных: `t1, t2, d1, d2, λ1, λ2, N`
2. Расчет `g1, g2` и температуры стыка `tc`
3. Вывод `tc` с точностью 3 знака после запятой
4. Цикл `for (i = 0; i < N; i++)`:
   a. Ввод `T`
   b. Ветвление `if (T > tc)` — определение слоя
   c. Расчет координаты по соответствующей формуле
   d. Вывод координаты

### 5. Выходные данные

* `Temperature at the layer interface: <tc>` — температура на стыке слоев
* Для каждой запрошенной температуры — координата `x` в метрах, отсчитанная от внутренней поверхности. Форматирование через `setw(60)` для наглядного столбца.

### 9. Особенности и ограничения

* В коде нет проверки на `wide1 == 0` или `wide2 == 0` — будет деление на ноль.
* Логика `if (tempCoord > tc)` корректна только если `t1 > t2`. Если внутренняя стена холоднее наружной (`t1 < t2`), условие нужно инвертировать или заменить на проверку попадания в интервал.
* Если запрошенная `T` выходит за пределы `[min(t1,t2), max(t1,t2)]`, координата будет экстраполирована за пределы стенки — физически это не имеет смысла.
* Ввод в сантиметрах, вывод в метрах — это сделано специально (`/ 100.0`).
